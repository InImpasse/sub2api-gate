Architecture

How the real stack works

These are the pieces represented by the sanitized repository.

1. Cloudflare Worker Handles `/allow-ip`, admin actions, UUID records, and Rules List writes.
2. Origin sync service Receives signed provisioning requests and updates Sub2API users and API keys.
3. Sub2API runtime Runs behind Docker Compose with PostgreSQL and Redis.
4. Nginx + WAF Restricts the API to approved IPs while keeping the allowlist page public.
